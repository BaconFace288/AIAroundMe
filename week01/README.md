### Quick Reference: The One Test
> **"Did a person write the rules, or did the computer learn them from examples?"**
> - If a person wrote the rules $\rightarrow$ **Not AI** (e.g. calculator, alarm clock, scripted game enemy).
> - If the computer learned from examples $\rightarrow$ **AI** (e.g. face unlock, recommendation feeds, autocorrect).
